Known limitation confirmed live: the GPU exporter's nvidia-smi-sourced
metrics never populate (nvidia_smi_last_collect_success stays 0) - the
image has no /usr/bin for CDI's symlink hook to inject nvidia-smi into.
See deploy/observability/gpu-exporter.yaml's header comment and ADR 0023.
vLLM's own /metrics (queue depth, request counts) is unaffected.
